#  AI-Based Learning Management System (LMS)

This is a web-based Learning Management System built using **Django (Python)** with basic **AI Tutor functionality**.

---

## Features

###  Teacher
- Register & Login
- Add Courses
- Upload Notes (PDF)
- Create Quiz Questions
- View Dashboard

###  Student
- Register & Login
- View Courses
- Download Notes
- Attempt Quiz
- View Dashboard

### AI Tutor
- Answers student questions
- Covers topics like Python, Django, HTML, AI, Database, etc.

---

## Technologies Used

- Python 3
- Django
- HTML & CSS
- SQLite Database
